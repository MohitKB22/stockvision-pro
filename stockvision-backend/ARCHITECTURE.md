# Architecture

This document moved to [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) at the
repository root, so backend and frontend architecture are described in one place.

The v1 version of this file documented the authentication subsystem, role-based
access control and the user/ownership model — all removed in v2.0. Leaving it in
place would have been worse than deleting it: stale architecture docs get trusted.
